Modo aula

10.1 - Séries de Fourier

A ferramenta matemática

1. Motivação

Até agora, quando resolvemos EDOs lineares não homogêneas, a força externa (a parte não homogênea) era quase sempre um polinômio, uma exponencial, um seno ou um cosseno. Para esses casos, o método dos coeficientes a determinar resolve o problema rapidamente. Mas, em muitas aplicações, a força externa é periódica sem ser uma senoide: uma onda quadrada, uma onda triangular, um dente de serra, um pulso que se repete. Como tratar esses casos?

A ideia, devida a Joseph Fourier (1807), é escrever uma função periódica qualquer como uma soma de senos e cossenos. Se a EDO é linear, o princípio da linearidade nos permite resolver a equação para cada seno e cada cosseno separadamente e, no final, somar as respostas. Ou seja, trocamos um problema difícil por infinitos problemas fáceis, que já sabemos resolver.

2. A série de Fourier

*: O livro usa \(x\) como variável inde- pendente nesse capítulo. Nas aplica- ções a EDOs, voltaremos a usar \(t\).

Seja \(f\) uma função periódica de período \(2L\), isto é, \(f(x+2L) = f(x)\) para todo \(x\). Sua série de Fourier é

\[ f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left[ a_n\cos\frac{n\pi x}{L} + b_n\sen\frac{n\pi x}{L} \right]. \]

Note que cada termo \(\cos(n\pi x/L)\) e \(\sen(n\pi x/L)\) também têm período \(2L\) (na verdade, período \(2L/n\)), de modo que a soma inteira se repete a cada \(2L\), como \(f(x)\). O termo de ordem \(n\) é chamado de \(n\)-ésimo harmônico, e sua frequência é \(n\pi/L\). O primeiro harmônico (\(n = 1\)) é a fundamental.

Restam duas perguntas: como calcular os coeficientes \(a_n\) e \(b_n\)? E a série realmente converge para \(f(x)\)? Começamos pela primeira, que depende de uma propriedade muito especial dos senos e cossenos.

1

3. Ortogonalidade

Assim como fazemos com vetores, podemos definir um produto interno entre funções. Para duas funções \(f(x)\) e \(g(x)\) definidas em \([-L, L]\), definimos

\[ \langle f, g\rangle = \int_{-L}^{L} f(x)\,g(x)\,dx. \]

Essa operação tem as mesmas propriedades do produto escalar de vetores: é simétrica, linear em cada argumento e \(\langle f, f\rangle > 0\) se \(f\) não é identicamente nula. Por analogia, dizemos que \(f(x)\) e \(g(x)\) são ortogonais quando \(\langle f, g\rangle = 0\), assim como os vetores \(\vec i\) e \(\vec j\), cujo produto escalar é zero.

Os senos e cossenos da série de Fourier são ortogonais entre si. Mais precisamente, para \(m, n \ge 1\) inteiros, valem

\[ \int_{-L}^{L} \sen\frac{m\pi x}{L}\,\sen\frac{n\pi x}{L}\,dx = \begin{cases} 0, & m \ne n,\\ L, & m = n, \end{cases} \] \[ \int_{-L}^{L} \cos\frac{m\pi x}{L}\,\cos\frac{n\pi x}{L}\,dx = \begin{cases} 0, & m \ne n,\\ L, & m = n, \end{cases} \]
\[ \int_{-L}^{L} \sen\frac{m\pi x}{L}\,\cos\frac{n\pi x}{L}\,dx = 0 \quad \mt{para quaisquer } m, n. \]

Ou seja, dois senos diferentes, dois cossenos diferentes, ou um seno e um cosseno quaisquer têm produto interno nulo. Só o produto interno de uma função com ela mesma não se anula, e vale \(L\). A série de Fourier é, então, a decomposição de \(f(x)\) numa base ortogonal de funções, e cada coeficiente será a projeção ortogonal de \(f(x)\) sobre um elemento dessa base, como veremos na próxima seção.

Vamos demonstrar o primeiro caso. Usando a identidade

\[ \sen A \sen B = \tfrac12\big[\cos(A-B) - \cos(A+B)\big], \]

para \(m \ne n\), inteiros. Se \(\red{a} = m-n\) e \(\red{b} = m+n\), também inteiros, temos

\[ \int_{-L}^{L} \sen\frac{\red m\pi x}{L}\sen\frac{\red n\pi x}{L}\,dx = \frac12\int_{-L}^{L}\left[\cos\frac{\red{a}\pi x}{L} - \cos\frac{\red{b}\pi x}{L}\right]dx \]
\[ = \frac12\left[\frac{L}{a\pi}\sen\frac{a\pi x}{L} - \frac{L}{b\pi}\sen\frac{b\pi x}{L}\right]_{-L}^{L} = 0, \]

pois \(\sen(k\pi) = 0\) para todo inteiro \(k\). Se \(m = n\), o primeiro cosseno vira \(\cos 0 = 1\), e a integral vale \(\frac12 \cdot 2L = L\). As outras duas integrais se verificam do mesmo modo.

2

4. Os coeficientes (fórmulas de Euler–Fourier)

A demonstração acima nos dá um método para deduzir os coeficientes \(a_n\) e \(b_n\) da Série de Fourier. Suponha que \(f(x)\) tenha a série de Fourier da seção 2. Para obter o \(b_m\), multiplicamos os dois lados por \(\red{\sen(m\pi x/L)}\) e integramos de \(-L\) a \(L\):

\[ \red{\int_{-L}^{L}} f(x)\red{\sen\tfrac{m\pi x}{L}\,dx} = \red{\int_{-L}^{L}}\frac{a_0}{2} + \sum_{n=1}^{\infty}\left[ a_n\cos\frac{n\pi x}{L} + b_n\sen\frac{n\pi x}{L} \right]\red{\sen\tfrac{m\pi x}{L}\,dx}. \]
Do que vimos na seção anterior, do lado direito, apenas não dá zero as integrais com \(b_n\) onde \(n = m\). Logo,
\[ \red{\int_{-L}^{L}} f(x)\red{\sen\tfrac{m\pi x}{L}\,dx} = b_n\int_{-L}^{L}\sin^2\frac{n\pi x}{L}\,dx = b_n\int_{-L}^{L}\frac12\,dx = b_n\frac{2L}{2} \]
Que, aplicada a fórmula de arco dobro, a parte do cosseno também dá zero. Assim,
\[ \int_{-L}^{L} f(x)\sen\frac{m\pi x}{L}\,dx = b_m\,L. \]

Fazendo o mesmo com \(\cos(m\pi x/L)\) obtemos \(a_m\). Trocando \(m\) por \(n\):

\[ a_n = \frac1L\int_{-L}^{L} f(x)\cos\frac{n\pi x}{L}\,dx, \quad n = 0, 1, 2, \ldots \] \[ b_n = \frac1L\int_{-L}^{L} f(x)\sen\frac{n\pi x}{L}\,dx, \quad n = 1, 2, \ldots \]
*: Por isso escrevemos \(a_0/2\) na série: assim uma única fórmula serve para todos os \(a_n\).

Para \(n = 0\), o seno é zero e \(\cos 0=1\). Assim, a fórmula dá \(a_0 = \frac1L\int_{-L}^{L} f(x)\,dx\), e o termo constante da série, \(a_0/2\), é simplesmente o valor médio de \(f(x)\) num período.

Como o integrando tem período \(2L\), as integrais podem ser feitas em qualquer intervalo de comprimento \(2L\), por exemplo \([0, 2L]\). Escolha o mais conveniente para a função dada.

3

5. Convergência

Até aqui supusemos que a série converge para \(f(x)\). Isso nem sempre é verdade, mas o teorema a seguir cobre praticamente todas as funções que aparecem em engenharia. Lembremos que uma função é seccionalmente contínua num intervalo quando tem no máximo um número finito de descontinuidades nele, todas de salto (isto é, os limites laterais existem e são finitos).

Teorema de Fourier. Suponha que \(f\) e \(f'\) sejam seccionalmente contínuas em \([-L, L)\) e que \(f(x)\) seja periódica de período \(2L\). Então a série de Fourier de \(f\) converge, em cada ponto \(x\), para

  • \(f(x)\), se \(f\) é contínua em \(x\);
  • \(\dfrac{f(x^+) + f(x^-)}{2}\), a média dos limites laterais, se \(f(x)\) tem um salto em \(x\).

Ou seja, nos pontos de salto, a série "escolhe" o ponto médio do salto, não importa qual valor \(f(x)\) tem ali.

Há um detalhe importante perto dos saltos. Ao somarmos apenas os \(N\) primeiros termos (a soma parcial \(S_N\)), a curva oscila e ultrapassa o valor da função perto do salto. Aumentando \(N\), a oscilação fica mais estreita, mas a ultrapassagem não diminui: ela tende a cerca de 9% do tamanho do salto. Esse é o fenômeno de Gibbs, e você o verá no gráfico do Exemplo 1.

6. Funções pares e ímpares

Muitas vezes, metade dos coeficientes é zero, e podemos saber disso antes de fazer qualquer conta. Lembremos que \(f\) é par se \(f(-x) = f(x)\) (gráfico simétrico em relação ao eixo \(y\), como \(\cos x\) e \(x^2\)) e ímpar se \(f(-x) = -f(x)\) (simétrico em relação à origem, como \(\sen x\) e \(x^3\)). Duas propriedades decorrem diretamente disso:

\[ f(x) \mt{ par} \Imp \int_{-L}^{L} f(x)\,dx = 2\int_0^L f(x)\,dx, \qquad f(x) \mt{ ímpar} \Imp \int_{-L}^{L} f(x)\,dx = 0. \]

Além disso, o produto de duas funções pares ou de duas ímpares é par, e o produto de uma par por uma ímpar é ímpar, exatamente como nos números naturais.

Aplicando isso às fórmulas de Euler–Fourier: se \(f\) é par, então \(f(x)\sen(n\pi x/L)\) é ímpar e todos os \(b_n\) se anulam; se \(f\) é ímpar, então \(f(x)\cos(n\pi x/L)\) é ímpar e todos os \(a_n\) se anulam. Assim,

4

\(f\) par: \(b_n = 0\) e a série só tem cossenos, com \(\displaystyle a_n = \frac2L\int_0^L f(x)\cos\frac{n\pi x}{L}\,dx.\)

\(f\) ímpar: \(a_n = 0\) e a série só tem senos, com \(\displaystyle b_n = \frac2L\int_0^L f(x)\sen\frac{n\pi x}{L}\,dx.\)

Exemplo 1: a onda quadrada.

Encontre a série de Fourier da função de período \(2L\) dada por

\[ f(x) = \begin{cases} -1, & -L < x < 0, \\ \phantom{-}1, & \phantom{-}0 < x < L, \end{cases} \qquad f(x + 2L) = f(x). \]

Primeiramente, note que \(f\) é ímpar. Logo, \(a_n = 0\) para todo \(n\), e só precisamos calcular os \(b_n\), integrando apenas em \([0, L]\), onde \(f = 1\):

\[ b_n = \frac2L\int_0^L 1\cdot\sen\frac{n\pi x}{L}\,dx = \frac2L\left[-\frac{L}{n\pi}\cos\frac{n\pi x}{L}\right]_0^L = \frac{2}{n\pi}\big(1 - \red{\cos n\pi}\big). \]
*: Será sempre útil lembrar que  \(\cos n\pi = (-1)^n\) e \(\sen n\pi = 0\).

Como \(\red{\cos n\pi = (-1)^n}\), temos \(1 - (-1)^n = 2\) para \(n\) ímpar e \(0\) para \(n\) par. Assim,

\[ b_n = \begin{cases} \dfrac{4}{n\pi}, & n \mt{ ímpar},\\[4pt] 0, & n \mt{ par}, \end{cases} \]

e a série de Fourier da onda quadrada é

\[ f(x) = \frac4\pi\left[ \sen\frac{\pi x}{L} + \frac13\sen\frac{3\pi x}{L} + \frac15\sen\frac{5\pi x}{L} + \cdots \right] = \frac4\pi\sum_{n \mt{ ímpar}}\frac1n\sen\frac{n\pi x}{L}. \]

Note que só aparecem harmônicos ímpares. Isso não é coincidência, e será explicado logo após este exemplo. Note também que, em \(x = 0\), todos os senos se anulam e a série dá \(0\), que é exatamente a média do salto de \(-1\) para \(1\), como garante o Teorema de Fourier.

O gráfico abaixo mostra as somas parciais \(S_N\) para alguns valores de \(N\). Observe como a aproximação melhora com \(N\), mas o "chifre" perto dos saltos (fenômeno de Gibbs) continua com a mesma altura, apenas mais estreito.

5

Por fim, observe que os coeficientes decaem como \(1/n\). Isso é típico de funções com saltos: a série precisa de muitos harmônicos altos para "construir" uma descontinuidade. Funções mais suaves têm coeficientes que decaem mais depressa, como veremos no próximo exemplo.

Simetria de meia-onda.

No Exemplo 1, só apareceram harmônicos ímpares. Isso se deve a uma terceira simetria, menos conhecida e muito útil. Dizemos que \(f(x)\) tem simetria de meia onda se

\[ f(x + L) = -f(x), \]

isto é, a segunda metade do período é a primeira "de cabeça para baixo". No gráfico abaixo, a curva tracejada é a primeira metade apenas deslocada de \(L\); a segunda metade de \(f(x)\) é essa cópia refletida no eixo \(x\).

6

Nesse caso, todos os harmônicos pares se anulam (\(a_n = b_n = 0\) para \(n\) par), e a série só tem harmônicos ímpares. A justificativa é que, para \(n\) par, \(\cos(n\pi x/L)\) e \(\sen(n\pi x/L)\) se repetem após um deslocamento de \(L\), enquanto \(f(x)\) troca de sinal; assim, nas integrais de \(a_n\) e \(b_n\), as contribuições das duas metades do período se cancelam.

*: Essa simetria será decisiva quando estudarmos a ressonância, na seção 9.

Atenção: a simetria de meia onda não tem relação com a paridade. Ela compara a função com ela mesma deslocada de meio período, e não refletida em torno da origem. A função do gráfico, por exemplo, não é par nem ímpar; já \(\cos(\pi x/L)\) é par e tem simetria de meia onda. A onda quadrada do Exemplo 1 tem as duas propriedades: é ímpar, por isso só tem senos, e tem simetria de meia onda, por isso só tem harmônicos ímpares.

Exemplo 2: a onda triangular.

Encontre a série de Fourier da função de período \(2L\) dada por \(f(x) = |x|\) em \(-L \le x \le L\).

Agora \(f\) é par. Logo, \(b_n = 0\), e calculamos os \(a_n\) em \([0, L]\), onde \(f(x) = x\). Para \(n = 0\),

\[ a_0 = \frac2L\int_0^L x\,dx = \frac2L\cdot\frac{L^2}{2} = L. \]
*: Integração por partes, com \(u = x\) e \(dv = \cos\frac{n\pi x}{L}dx\).

Para \(n \ge 1\), integrando por partes,

\[ \begin{aligned} a_n &= \frac2L\int_0^L x\cos\frac{n\pi x}{L}\,dx = \frac2L\left[\frac{L x}{n\pi}\sen\frac{n\pi x}{L} + \frac{L^2}{n^2\pi^2}\cos\frac{n\pi x}{L}\right]_0^L \\ &= \frac{2L}{n^2\pi^2}\big(\red{\cos n\pi} - 1\big). \end{aligned} \]

Novamente, \(\cos n\pi - 1 = (-1)^n - 1\) vale \(-2\) para \(n\) ímpar e \(0\) para \(n\) par. Assim, \(a_n = -\dfrac{4L}{n^2\pi^2}\) para \(n\) ímpar e

\[ |x| = \frac L2 - \frac{4L}{\pi^2}\left[\cos\frac{\pi x}{L} + \frac19\cos\frac{3\pi x}{L} + \frac1{25}\cos\frac{5\pi x}{L} + \cdots\right], \qquad -L \le x \le L. \]

Compare com o Exemplo 1. Aqui a função é contínua (só a derivada tem "bicos"), e os coeficientes decaem como \(1/n^2\), muito mais rápido. Na prática, poucos termos já dão uma excelente aproximação, e não há fenômeno de Gibbs. O termo \(L/2\) é o valor médio de \(|x|\) no período.

7

Note que aqui também só aparecem harmônicos ímpares (fora o termo constante), mas \(|x|\) não tem simetria de meia onda: ela nunca é negativa e, por exemplo, \(f(L) = L\), enquanto \(-f(0) = 0\). Quem tem a simetria é a função sem o valor médio, \(g(x) = |x| - L/2\). De fato, para \(-L < x < 0\),

\[ g(x+L) = (x + L) - \tfrac{L}{2} = x + \tfrac{L}{2} = -\left(-x - \tfrac{L}{2}\right) = -g(x), \]

e para \(0 < x < L\) a conta é análoga. Como subtrair uma constante só altera \(a_0\), os harmônicos pares se anulam do mesmo jeito. De modo geral, \(f(x)\) tem só harmônicos ímpares (fora o termo constante) quando \(f(x) - a_0/2\) tem simetria de meia onda.

Mais uma observação interessante: derivando a série termo a termo,

\[ \frac{d}{dx}|x| = \frac{4L}{\pi^2}\sum_{n \mt{ ímpar}}\frac{1}{n^2}\cdot\frac{n\pi}{L}\sen\frac{n\pi x}{L} = \frac4\pi\sum_{n\mt{ ímpar}}\frac1n\sen\frac{n\pi x}{L}, \]

que é exatamente a onda quadrada do Exemplo 1! E de fato, a derivada de \(|x|\) é \(-1\) para \(x < 0\) e \(1\) para \(x > 0\). Essa relação entre suavidade e decaimento dos coeficientes é uma das ideias mais úteis da teoria.

7. Aplicação a EDOs: superposição

Agora usaremos a série de Fourier para resolver EDOs. Considere uma EDO linear com coeficientes constantes,

\[ \mathcal{L}[y] = f(t), \]
8

onde \(\mathcal{L}[y]\) representa o lado esquerdo (por exemplo, \(\mathcal{L}[y] = a y' + y\) ou \(\mathcal{L}[y] = y'' + \omega^2 y\)) e \(f\) é periódica. Lembremos que a solução geral de uma EDO linear é sempre a soma da solução geral da homogênea com uma solução particular. A solução da homogênea não depende de \(f\); o trabalho todo está na solução particular.

Se \(f(t) = f_1(t) + f_2(t) + \cdots\)  e seja \(y_n\) uma solução particular de \(\mathcal{L}[y_n] = f_n\), então, pela linearidade,

\[ \mathcal{L}[y_1 + y_2 + \cdots] = \mathcal{L}[y_1] + \mathcal{L}[y_2] + \cdots = f_1 + f_2 + \cdots = f. \]

Ou seja, \(y_p = y_1 + y_2 + \cdots\) é uma solução particular da equação original. Esse é o princípio da superposição, e ele nos dá a seguinte estratégia:

  1. Escreva \(f\) como série de Fourier.
  2. Para cada harmônico, ache a solução particular, que é a resposta a um único seno ou cosseno.
  3. Some as respostas.

O passo 2 é o mesmo para todos os harmônicos, só muda a frequência. Então basta resolvê-lo uma vez, para uma senoide genérica \(b\sen\red c t\), e depois substituir \(\red c = n\pi/L\). É o que faremos nas próximas seções, para equações de primeira e de segunda ordem.

8. Resposta a uma senoide: primeira ordem

Considere

\[ a\,y' + y = b\sen\red c t, \qquad a > 0. \]

Pelo método dos coeficientes a determinar, procuramos \(y_p = A\sen\red c t + B\cos\red c t\). Então \(y_p' = A\red c\cos\red c t - B\red c\sen\red c t\) e, substituindo na EDO, temos

\[ (A - a\red c B)\sen\red c t + (a\red c A + B)\cos\red c t = b\sen\red c t. \]

Comparando os coeficientes, \(A - a\red c B = b\) e \(a\red c A + B = 0\). Da segunda, \(B = -a\red c A\); substituindo na primeira,

\[ A\big(1 + (a\red c)^2\big) = b \Imp A = \frac{b}{1 + (a\red c)^2}, \qquad B = -\frac{ab\red c}{1 + (a\red c)^2}. \]
9
*: Usamos \(A\sen\theta + B\cos\theta = R\sen(\theta - \varphi)\), com \(R = \sqrt{A^2 + B^2}\) e \(\tg\varphi = -B/A\).

É mais revelador escrever a resposta como uma única senoide, com amplitude e fase:

\[ y_p = \red{\frac{1}{\sqrt{1 + (ac)^2}}}\; b\sen(\red c t - \varphi), \qquad \tg\varphi = a\red c. \]

Leia essa fórmula com calma. A resposta é uma senoide com a mesma frequência da entrada, mas com a amplitude multiplicada pelo fator em vermelho, que chamaremos de ganho, e atrasada de \(\varphi\). 

Agora, se a entrada for a onda quadrada do Exemplo 1 (na variável \(t\)), o \(n\)-ésimo harmônico tem amplitude \(4/(n\pi)\) e frequência \(\red{c_n} = n\pi/L\). Pela superposição,

\[ y_p(t) = \frac4\pi\sum_{n\mt{ ímpar}} \frac1n\cdot\red{\frac{1}{\sqrt{1 + (a c_n)^2}}}\,\sen\!\left(\red{c_n}t - \varphi_n\right), \qquad \tg\varphi_n = a\red{c_n}. \]

9. Resposta a uma senoide: segunda ordem

Considere agora, sem amortecimento,

\[ y'' + \omega^2 y = b\sen\red c t, \]

cuja homogênea tem soluções \(\cos\omega t\) e \(\sen\omega t\). Chamamos \(\omega\) de frequência natural. Há dois casos.

Caso \(\red c \ne \omega\) (caso geral). Como não há termo em \(y'\), basta tentar \(y_p = A\sen\red c t\): \(\;-A\red c^2 + \omega^2 A = b\), logo

\[ y_p = \frac{b}{\omega^2 - \red c^2}\sen\red c t. \]
*: Já vimos esse caso: quando a força externa é solução da homogênea, multiplicamos a tentativa por \(t\).

Caso \(\red c = \omega\) (ressonância). Agora \(\sen\omega t\) é solução da homogênea, e a tentativa é \(y_p = t(A\cos\omega t + B\sen\omega t)\). As contas levam a

\[ y_p = \red{-\frac{b\,t}{2\omega}}\cos\omega t. \]

Sempre podemos verificar a solução. Derivando duas vezes,

\[ y_p'' = b\sen\omega t + \frac{b\omega}{2}\,t\cos\omega t \Imp y_p'' + \omega^2 y_p = b\sen\omega t + \frac{b\omega}{2}t\cos\omega t - \frac{b\omega}{2}t\cos\omega t \] \[ \Imp y_p'' + \omega^2 y_p = b\sen\omega t. \]
10

A amplitude de \(bt/(2\omega)\) cresce sem limite com o tempo. Esse é o fenômeno da ressonância. Você deve estar atento à possibilidade de haver um harmônico ressonante, e tratar este caso separadamente dos demais harmônicos.

Se \(f\) é periódica de período \(2L\), sua série contém as frequências \(\red{c_n} = n\pi/L\), \(n = 1, 2, 3, \ldots\) Assim:

Há ressonância se algum harmônico presente na série de \(f\) tiver frequência igual a \(\omega\), isto é, se \(n\pi/L = \omega\) para algum \(n\) com coeficiente não nulo. 

Uma força externa de frequência fundamental bem diferente de \(\omega\) pode, portanto, provocar ressonância por meio de um de seus harmônicos. E, ao contrário, a ausência de certos harmônicos (por exemplo, por simetria de meia onda) pode impedir uma ressonância que parecia inevitável. O exemplo a seguir mostra os dois casos.

Exemplo 3: ressonância num harmônico.

Seja \(f\) a onda quadrada do Exemplo 1, com período \(2L = 3\pi\). Encontre uma solução particular de

\[ y'' + 4y = f(t). \]

Aqui \(\omega = 2\) e \(L = 3\pi/2\), de modo que as frequências da série são \(\red{c_n} = n\pi/L = 2n/3\), para \(n\) ímpar (simetria de meia onda). A fundamental é \(\red{c_1} = 2/3\), bem abaixo de \(\omega = 2\). Mas, para \(n = 3\), \(\red{c_3} = 2 = \omega\): o terceiro harmônico está em ressonância.

Para \(n \ne 3\), estamos no caso \(\red c \ne \omega\), com \(b_n = 4/(n\pi)\) para a onda quadrada. Logo 

\[ y_p = \frac{b}{\omega^2 - \red c^2}\sen\red c t \Imp y_n = \frac{4}{n\pi}\cdot\frac{1}{4 - 4n^2/9}\sen\frac{2nt}{3} \]
\[ y_n = \frac{9}{n\pi(9 - n^2)}\sen\frac{2nt}{3}. \]

Para \(n = 3\), temos o caso ressonante com \(b = 4/(3\pi)\):

\[ y_3 = \red{-\frac{b\,t}{2\omega}}\cos\omega t = -\frac{4}{3\pi}\cdot\frac{t}{2\cdot 2}\cos 2t = \red{-\frac{t}{3\pi}\cos 2t}. \]

Logo,

\[ y_p(t) = -\frac{t}{3\pi}\cos 2t + \sum_{\substack{n\mt{ ímpar}\\ n\ne 3}}\frac{9}{n\pi(9 - n^2)}\sen\frac{2nt}{3}. \]

E se o período fosse \(2\pi\)? Então \(L = \pi\) e \(\red{c_n} = n\pi/L = n\). Seria natural pensar que o segundo harmônico (\(\red{c_2} = 2\)) entra em ressonância. Mas a onda quadrada não tem harmônicos pares, por causa da simetria de meia onda. Assim, nenhum harmônico tem frequência \(2\), e não há ressonância. Em geral, para a onda quadrada e \(\omega = 2\), há ressonância exatamente quando \(2L = n\pi\) para algum \(n\) ímpar.

10. Um atalho: a exponencial complexa

Nas seções 8 e 9, refizemos o método dos coeficientes a determinar para cada equação. Há um caminho mais curto, que será muito usado nas disciplinas seguintes, usando a fórmula de Euler, \(e^{i\red c t} = \cos\red c t + i\sen\red c t\). Se acharmos a resposta à entrada complexa \(e^{i\red c t}\), a resposta a \(\sen\red c t\) será sua parte imaginária.

Tentando \(y_p = H\,e^{i\red c t}\), cada derivada apenas multiplica por \(i\red c\). Então:

\[ a\,y' + y = e^{i\red c t} \Imp (i a\red c + 1)H = 1 \Imp H(i\red c) = \frac{1}{1 + i a\red c}, \]
\[ y'' + \omega^2 y = e^{i\red c t} \Imp (-\red c^2 + \omega^2)H = 1 \Imp H(i\red c) = \frac{1}{\omega^2 - \red c^2}. \]
*: \(H\) é a mesma função de transferên- cia obtida com a transformada de Laplace, avaliada em \(s = i\red c\).

O número complexo \(H(i\red c)\) contém toda a informação: o ganho é \(|H(i\red c)|\) e a defasagem é \(-\arg H(i\red c)\). Por exemplo, \(|1/(1 + ia\red c)| = 1/\sqrt{1 + (a\red c)^2}\), exatamente o ganho da seção 8, sem refazer conta nenhuma. Com isso, a resposta a uma entrada periódica qualquer se resume a: cada harmônico sai multiplicado por \(H\) avaliado na sua frequência.

Resumo

  • Uma função periódica de período \(2L\) se escreve como soma de harmônicos de frequências \(n\pi/L\) (seção 2).
  • Senos e cossenos são ortogonais; por isso, cada coeficiente é uma integral, uma "projeção" (seções 3 e 4).
  • A série converge para \(f\) nos pontos de continuidade e para a média nos saltos; perto dos saltos ocorre o fenômeno de Gibbs (seção 5).
  • Função par: só cossenos. Ímpar: só senos. Meia onda: só harmônicos ímpares (seção 6).
  • Saltos dão coeficientes \(\sim 1/n\); funções contínuas com "bicos", \(\sim 1/n^2\) (Exemplos 1 e 2).
  • Para EDOs lineares, resolva cada harmônico e some (superposição). 
  • A 2ª ordem ressoa se algum harmônico coincidir com \(\omega\) (seção 9).

Leitura no livro: Boyce & DiPrima, seções 10.2 (séries de Fourier), 10.3 (teorema de convergência) e 10.4 (funções pares e ímpares).
